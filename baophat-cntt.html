Phần Cứng Máy Tính

CPU là bộ não xử lý lệnh. RAM lưu dữ liệu tạm. Ổ cứng HDD/SSD lưu dài hạn. GPU xử lý đồ họa. Mainboard kết nối tất cả.

🔗

Mạng Máy Tính

Mạng LAN kết nối thiết bị cục bộ. Internet là mạng toàn cầu. TCP/IP là giao thức truyền dữ liệu cơ bản. HTTP/HTTPS dành cho web.

🗄️

Cơ Sở Dữ Liệu

CSDL lưu trữ dữ liệu có cấu trúc. SQL (MySQL, PostgreSQL) dạng bảng. NoSQL (MongoDB) dạng tài liệu linh hoạt.

☁️

Điện Toán Đám Mây

Cloud Computing cung cấp tài nguyên qua internet. AWS, Google Cloud, Azure là 3 nhà cung cấp lớn nhất thế giới hiện nay.

🔐

Bảo Mật Thông Tin

Mã hóa bảo vệ dữ liệu. Firewall chặn truy cập trái phép. SSL/TLS bảo mật kết nối web. Cần backup dữ liệu thường xuyên.

🤖

Trí Tuệ Nhân Tạo

AI mô phỏng trí tuệ con người. Machine Learning tự học từ dữ liệu. Deep Learning dùng mạng nơ-ron nhiều lớp để phân tích.
